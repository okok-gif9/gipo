# برنامهٔ اجرایی بازطراحی گیپو

1. ساختار پوستهٔ فعلی، وابستگی‌های آیکن و الگوی دادهٔ شخصیت‌ها بررسی می‌شود. منطق Supabase، احراز هویت، RLS و توابع داستان از نمایش جدا می‌مانند.
2. یک مجموعهٔ طراحی مستقل شامل متغیرهای رنگ روشن/تاریک، فاصله‌گذاری، گوشه‌ها، تایپوگرافی و قواعد حرکت کم‌مصرف اضافه می‌شود. تم روشن «سیارهٔ کاغذی» و تم تیره «کتابخانهٔ فانوسی» با متغیرهای CSS پیاده‌سازی می‌شوند.
3. نشان برداریِ اختصاصی GIPO به‌صورت کامپوننت کوچک و مقیاس‌پذیر طراحی می‌شود؛ فاوآیکن و متادیتای برنامه نیز با آن همسو خواهند شد.
4. پوستهٔ دسکتاپ به نوار کناری فشرده، هدر کوتاه، فیلترهای افقی قابل‌اسکرول و فضای کشف کارت‌محور تبدیل می‌شود. در موبایل، نوار کناری به ناوبری پایین تغییر می‌کند.
5. صفحه‌های کشف، داستان‌های من، ساخت جهان، گفت‌وگو و تنظیمات با همین سیستم، کارت‌های حرفه‌ای و وضعیت‌های خالی واضح بازسازی می‌شوند. کارت بی‌تصویر یک قاب تایپوگرافیک دارد و هرگز به آواتار کودکانه تبدیل نمی‌شود.
6. Lucide برای همهٔ آیکن‌های محصولی و Motion for React برای انتقال‌های کوتاه و هدفمند استفاده می‌شود. حرکت‌های غیرضروری، نشانه‌های ربات/هوش مصنوعی و آیکن‌های تکراری وارد نمی‌شوند.
7. آزمون‌های ساخت، واحد و رابط برای پوستهٔ جدید، تم‌ها، RTL/LTR و کنترل‌های دسترس‌پذیر به‌روزرسانی می‌شوند. سپس خروجی GitHub Pages از نظر بصری و واکنش‌گرا بررسی، ثبت و منتشر می‌شود.
